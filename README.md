# -

โปรเจกต์ในเรพอนี้:

- **`scoring/`** — ระบบให้คะแนน/ลบคะแนนจิตพิสัยนักเรียน แยกตามห้องเรียน
  - `artifact.html` — เวอร์ชันที่ publish เป็น Claude Artifact (ลิงก์ใช้งานจริง) ข้อมูลซิงค์อัตโนมัติผ่าน Artifact database (`db` capability) ใช้ได้จากหลายเครื่อง/หลายอุปกรณ์ พร้อมบันทึกไฟล์ CSV/JSON ผ่าน `downloads` capability ไฟล์นี้**ไม่มีรายชื่อนักเรียนจริงฝังอยู่ในโค้ด** — ข้อมูลนักเรียนถูก seed ไว้ในฐานข้อมูลของ Artifact แยกต่างหาก (ไม่อยู่ใน git) เพื่อความเป็นส่วนตัว
  - `index.html` / `style.css` / `app.js` — เวอร์ชัน static เดี่ยวๆ (ไม่ต้องพึ่ง Claude Artifact) เก็บข้อมูลใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ใช้เมื่อต้องการรันเองนอกระบบ Artifact (เช่น GitHub Pages)
  - ทั้งสองเวอร์ชัน: เพิ่ม/แก้ไข/ลบห้องเรียนและนักเรียน (เลขที่ + ชื่อ-สกุล), นำเข้ารายชื่อแบบวางข้อความทีเดียวทั้งห้อง, ให้คะแนน (บวก/ลบ) พร้อมเหตุผลและวันที่, ดูประวัติ/ลบรายการคะแนนที่บันทึกผิด, ส่งออก CSV, พิมพ์รายงาน
- **`index.html` / `game.js` / `style.css`** (root) — เกม Star Blaster
