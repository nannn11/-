# -

โปรเจกต์ในเรพอนี้:

- **`scoring/`** — เครื่องมือบันทึกคะแนนจิตพิสัยนักเรียน มีสองเวอร์ชันที่แยกจุดประสงค์กัน:
  - `artifact.html` — เวอร์ชันที่ publish เป็น Claude Artifact จริง (ลิงก์ใช้งานอยู่) **ปัจจุบันถูกปรับให้เป็นเครื่องมือวิจัยเฉพาะห้อง ป.1/3** (40 คน): บันทึกคะแนนแบบตาราง 4 ครั้งคงที่ ("ครั้งที่ 1-4") แต่ละครั้งให้คะแนนตามหัวข้อประเมินย่อย (ค่าเริ่มต้น 5 หัวข้อ แก้ไข/เพิ่ม/ลบได้ในหน้าเว็บ ผ่านปุ่ม "⚙️ หัวข้อประเมิน") ข้อละ 0-2 คะแนน รวมอัตโนมัติ ส่งออกเป็น CSV แบบ wide-format (ทุกครั้ง × ทุกหัวข้อ) พร้อมสำรอง/กู้คืนข้อมูลเป็น JSON ข้อมูลซิงค์อัตโนมัติผ่าน Artifact database (`db` capability) ไฟล์นี้**ไม่มีรายชื่อนักเรียนจริงฝังอยู่ในโค้ด** — รายชื่อและคะแนนถูกเก็บในฐานข้อมูลของ Artifact แยกต่างหาก (ไม่อยู่ใน git) เพื่อความเป็นส่วนตัว ข้อมูลของอีก 12 ห้องที่เคย seed ไว้ก่อนหน้านี้ยังอยู่ในฐานข้อมูลเดิม (ไม่ได้ลบ) เพียงแต่เว็บเวอร์ชันนี้ไม่ได้แสดง/แก้ไขห้องอื่นแล้ว
  - `index.html` / `style.css` / `app.js` — เวอร์ชัน static ทั่วไปแบบเดิม (หลายห้อง ให้/ลบคะแนนสะสมพร้อมประวัติแบบไม่จำกัดจำนวนครั้ง) ไม่ต้องพึ่ง Claude Artifact เก็บข้อมูลใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ใช้เมื่อต้องการเครื่องมือบริหารคะแนนความประพฤติทั่วไป (ไม่ใช่งานวิจัยที่มีโปรโตคอลตายตัว)
- **`index.html` / `game.js` / `style.css`** (root) — เกม Star Blaster
