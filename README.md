# -

โปรเจกต์ในเรพอนี้:

- **`scoring/`** — ระบบให้คะแนน/ลบคะแนนจิตพิสัยนักเรียน แยกตามห้องเรียน เปิด `scoring/index.html` ในเบราว์เซอร์เพื่อใช้งาน (ไม่ต้องติดตั้งอะไรเพิ่ม)
  - เพิ่ม/แก้ไข/ลบห้องเรียนและนักเรียน (เลขที่ + ชื่อ-สกุล) ได้ในหน้าเว็บ หรือนำเข้ารายชื่อแบบวางข้อความทีเดียวทั้งห้อง
  - ให้คะแนน (บวก/ลบ) พร้อมเหตุผลและวันที่ ดูประวัติคะแนนย้อนหลัง และลบรายการคะแนนที่บันทึกผิดได้
  - ข้อมูลถูกเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้งาน (localStorage) เท่านั้น — ใช้ปุ่ม "สำรองข้อมูล" / "กู้คืนข้อมูล" เพื่อสำรองหรือย้ายข้อมูลไปเครื่องอื่น
- **`index.html` / `game.js` / `style.css`** (root) — เกม Star Blaster
